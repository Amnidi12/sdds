# API Reference

Full interactive documentation is auto-generated by FastAPI and available at `/docs` (Swagger UI) and `/redoc` whenever `ENV != production`. This document is a quick-reference summary; the running `/docs` endpoint is always the source of truth.

Base path: `/api/v1`

## Error format

Every error response follows the same shape:

```json
{
  "error": {
    "code": "DONATION_NOT_FOUND",
    "message": "Donation was not found.",
    "request_id": "a1b2c3d4-..."
  }
}
```

`request_id` matches the `X-Request-ID` response header, useful for correlating a user-reported issue with server logs.

## Auth (`/auth`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | none | Create a donor/volunteer/beneficiary account (NGO/admin accounts are provisioned separately, not self-registered) |
| POST | `/auth/verify-email` | none | Verify email via emailed token |
| POST | `/auth/login` | none | Sets `access_token` + `refresh_token` HttpOnly cookies |
| POST | `/auth/refresh` | refresh cookie | Rotates the refresh token, issues a new access token |
| POST | `/auth/logout` | any | Revokes current session |
| POST | `/auth/logout-all` | any | Revokes all sessions for this user |
| GET | `/auth/me` | any | Returns the current user |
| POST | `/auth/change-password` | any | Requires current password |
| POST | `/auth/forgot-password` | none | Always returns a generic success message (anti-enumeration) |
| POST | `/auth/reset-password` | none | Consumes a reset token; revokes all existing sessions |

## Donations (`/donations`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/donations` | donor | Create a donation (status starts at `pending_review`) |
| GET | `/donations` | any authenticated | List, scoped by role (donor sees own, NGO staff see their org, admin sees all); supports `?status=`, `?category_id=`, `?page=`, `?page_size=` |
| GET | `/donations/{id}` | scoped | Full detail including status history |
| PATCH | `/donations/{id}/status` | ngo_admin/super_admin | State-machine-enforced transition; 409 on invalid transition |
| GET | `/donations/track/{tracking_id}` | **none (public)** | Minimal status view, no PII |

## Warehouses & Inventory (`/warehouses`, `/inventory`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/warehouses` | ngo_admin/super_admin | Create a warehouse |
| GET | `/warehouses` | ngo_admin/super_admin/volunteer | List, scoped by org |
| POST | `/inventory/receive/{donation_id}` | ngo_admin/super_admin | Verify a received donation into stock; advances donation to `available` |
| GET | `/inventory` | ngo_admin/super_admin | List batches, scoped by org |
| GET | `/inventory/alerts/low-stock` | ngo_admin/super_admin | Batches at or below `?threshold=` (default 5) |
| GET | `/inventory/alerts/expiring-soon` | ngo_admin/super_admin | Batches expiring within `?days=` (default 7) |
| POST | `/inventory/{batch_id}/reserve` | ngo_admin/super_admin | Row-locked reservation |
| POST | `/inventory/{batch_id}/release` | ngo_admin/super_admin | Release a reservation |
| POST | `/inventory/{batch_id}/dispatch` | ngo_admin/super_admin | Convert reservation to permanent OUT |

## Beneficiaries (`/beneficiaries`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/beneficiaries` | ngo_admin/super_admin | Create a beneficiary record |
| GET | `/beneficiaries` | ngo_admin/super_admin only | **Never public** — list is org-scoped and excludes `address` from the response |
| POST | `/beneficiaries/{id}/requests` | beneficiary (own)/ngo_admin/super_admin | Submit a resource request |
| GET | `/beneficiaries/{id}/requests` | beneficiary (own)/ngo_admin/super_admin | List requests |

## Distributions (`/distributions`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/distributions` | ngo_admin/super_admin | Creates + immediately reserves stock across one or more inventory batches |
| GET | `/distributions` | ngo_admin/super_admin/volunteer | Scoped by org or assigned volunteer |
| PATCH | `/distributions/{id}/status` | ngo_admin/super_admin/volunteer (assigned) | State-machine-enforced; `dispatched`→advances source donations to `out_for_distribution`, `delivered`→`delivered`, `completed`→`completed` (donor now sees impact) |
| POST | `/distributions/{id}/proof` | volunteer (assigned)/ngo_admin/super_admin | Record delivery confirmation |
